# Fourier Lab — フーリエ変換 学習シミュレータ

診療放射線技師国家試験の学習用に作成した，1次元・2次元フーリエ変換の可視化サイトです．HTML/CSS/JavaScriptのみで動作し，サーバ処理や外部ライブラリは使いません．

## 使い方

画面上部の「1次元」「2次元」タブを選び，左側で信号・画像テンプレートと操作を選択します．スライダーを動かすと，入力／操作後の波形・画像とそれぞれのスペクトルを同時に更新します．周波数領域の表示は振幅・位相・実部・虚部から切り替えられます．「逆フーリエ変換の復元結果」には逆変換した結果と数値誤差を表示します．

- **1D**：余弦，正弦，矩形，ガウス，インパルス，定数，複合波，偶関数，奇関数のテンプレート．位置移動，定数加算，定数倍，横方向の伸縮，加減算，畳み込み，乗算，偶奇分解，反転，複素変調，Hann窓，標本化・エイリアシング．
- **2D**：模擬医用画像，点・直線・矩形・円・ガウス・縞・格子・チェッカー，任意の画像アップロード．位置移動，輝度変更，倍率変更，回転，拡大縮小，加減算，ガウス畳み込み，ローパス／ハイパス／バンドパス，偶奇分解，振幅のみ・位相のみ再構成，簡易k空間．
- **共通**：性質の数式と解説，答えを選ぶ確認問題，初期化，レスポンシブ表示．

## GitHub Pagesへの公開

1. GitHubでリポジトリを作成（公開する場合はPublic）します．
2. **このフォルダ内の `index.html`, `styles.css`, `js/` などをリポジトリのルートに置きます**．`fourier-study-site` フォルダを1段多く置かないでください．
3. リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** を選択し，ブランチ `main`，フォルダ `/(root)` を保存します．
4. GitHub Pagesで公開されたURLを開きます．追加ビルド作業やAPIキーは不要です．

### ローカルプレビュー

ブラウザで `index.html` を直接開くと，ES Modulesの読み込みが制限される場合があります．このフォルダで次を実行してください．

```bash
python -m http.server 8000
```

ブラウザから `http://localhost:8000/` を開きます．Pythonがなければ任意の静的HTTPサーバでも構いません．

### 計算テスト（任意）

Node.js（18以上）で `npm test` を実行します．外部パッケージのインストールは不要です．

## 数学・計算上の前提

- **DFT**：`F[k] = Σ f[n] exp(-i 2π kn/N)`，逆変換 `f[n] = (1/N) Σ F[k] exp(i 2π kn/N)`．1Dは256点，2Dは128×128点のradix-2 FFTを用います．
- **1Dスペクトルの縦軸**：振幅は `|F|/N`，実部・虚部も `1/N` 規格化．位相はrad，振幅が最大値の0.01%以下の場所は未定義扱いで線を引きません．
- **2Dスペクトル**： `fftshift` で直流（DC）を中心に表示．対数振幅（デフォルト），線形振幅，位相，実部，虚部を選べます．同一操作の前後では同じ色スケールを使います．
- **DFTの周期性**：平行移動や畳み込みは循環処理です．有限長信号の単純なゼロ埋め移動や線形畳み込みとは異なります．
- **連続変換の性質**：時間・空間スケーリングおよび回転の式は連続変換のものです．画面での有限画像／信号の再標本化には端点・補間・エイリアシングによる差異があります．
- **標本化・エイリアシング**：1Dの標本化機能では，入力の解析的な信号を異なる標本間隔で再標本化します．両波形の横軸はそれぞれの標本番号です．周波数軸はそれぞれの離散ビンなので，2つのスペクトルのビン番号を同じ物理周波数として直接比較しないでください．
- **1D畳み込み**：補助カーネルは総和を1として循環畳み込みします．これにより平滑化における信号平均値を保ちます．
- **位相のみ再構成**：0でないスペクトル成分の振幅を平均値で統一します．0成分の位相は未定義なので0として扱います．
- **2D画像の画素値**：演算中は浮動小数で保持し，画素値は[0,1]にクリップしません．表示では共通スケールを使い，負値を含む場合は青（負）／橙（正）の符号付きカラーマップを使用します．
- **アップロード画像**：JavaScriptにより端末のブラウザ上でグレースケール128×128へ縮小します．ファイルはサーバへ送信せず，ページの読み直しで消えます．
- **MRIのk空間**：Cartesian k空間を想定した2D FFTの教育モデルです．MRI信号収集やコイル感度等は再現しません．

## テスト・検証

`tests/math.test.mjs` に，1D/2D FFTの逆変換，同じ振幅を保つ循環シフト，直流成分への定数加算，偶奇対称，畳み込み，複素変調，周波数マスク，再構成などの数値自動テストを含めています．`tests/ui-smoke.test.mjs` では，簡易DOMとCanvasを使って全操作の描画処理をスモークテストします（実ブラウザの視覚的検証ではありません）．
